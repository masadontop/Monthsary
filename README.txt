MONTHSARY WEBSITE
=================

Files:
- index.html
- style.css

To add your photos:
1. Put 5 photos in this same folder.
2. Rename them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg

To add music:
1. Put your music file in this same folder.
2. Rename it to:
   music.mp3

Then double-click index.html to open the website.

The website starts with a 3-second countdown, shows the title,
allows clicking the button OR anywhere on the title screen,
shows 5 photos, and opens the love letter after the fifth photo.
